# 潘帅跑步生涯看板 🏃

一个纯静态的单文件跑步生涯总览看板，数据来自 Coros API。

- **时间跨度**：2023-10-17 至今
- **内容**：生涯 KPI、PB 卡（点击展开单次详情）、年度 → 月度 → 单次三层下钻、跑步热力图、跑步足迹（国家/省份/地市）、半马与田协 10K 赛事徽章
- **PB**：半马 1:42:33（杭州）· 目标 1:40:00

## 使用

直接浏览器打开 `index.html` 即可，无任何外部依赖（CSS/JS 全部内联，离线可用）。

## 隐私说明

本仓库只包含生涯汇总看板；含逐点 GPS 坐标的「全部轨迹地图」未随仓库发布。

## 数据

数据每日从 Coros 同步后重新生成，当前更新至 **2026-10-21**（共 419 次跑步）。
